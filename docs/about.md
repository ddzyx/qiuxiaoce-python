# 关于球小策 (About QiuXiaoCe)

## 品牌背景

[球小策（qiuxiaoce.com）](https://www.qiuxiaoce.com) 创立于中国，是专注于足球垂直领域的专业级**大数据量化分析与 AI 赛前研报基础设施**。

我们致力于打破传统足球数据碎片化、指标单一的现状，通过标准化的数据流水线对全球赛事进行高精度的多维解析。

---

## 核心技术能力

1. **200+ 维赛前特征量化**: 涵盖基础面（联赛积分/主客场分化）、攻防节奏均值、预期进球（xG/xGA）、伤停战力折损模型。
2. **五维交叉仲裁体系**: 融合多源客观情报，杜绝主观臆测。
3. **极简开发者接入**: 支持 Python、Node.js、PHP、Go 与 Docker 终端工具全生态调用。
